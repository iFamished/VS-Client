# VSClient

## Requirements
- [Visual Studio Code](https://code.visualstudio.com/download)
- [Java 21 (JDK)](https://www.oracle.com/java/technologies/javase/jdk21-archive-downloads.html)
- Git

## Setup
Once you have met all the requirements, run this command in a built-in bash terminal in VSCode:
```
git clone https://github.com/iFamished/VS-Client.git && cd VS-Client
```
After the repository is cloned, you can launch the game. Launch using this command in a bash terminal:
```
./gradlew runClient
```
And you're good to go. To add mods, drop mods into the Mod Menu.
